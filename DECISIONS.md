# Decisions

- Select failure/recovery transitions over queue admission: a distinct lesson from existing rate budgets and retry effects.
- Build original inert standard-library logic after approval; candidate libraries execute live callables/time and differ on ignored exceptions. No source copied or package installed.
- Separate attempt/completion records so observations cannot silently belong to a rejected attempt. One breaker/pending record bounds ownership ambiguity.
- Closed overlap is outside this profile; half-open probe saturation is a declared serial-interleaving rule, not threaded safety.
- Use exact synthetic integer milliseconds, completion-time cooldown origin, equality eligibility and lazy transition on attempts. No aging/timers/retries.
- Neutral ignored outcome neither counts as failure nor establishes success. Explicitly differs from inspected excluded-exception reset behavior and Microsoft's time-based counter illustration.
- Preserve research provenance, raw local draft and inert source snapshots. No repository/application code before concrete-plan approval.
